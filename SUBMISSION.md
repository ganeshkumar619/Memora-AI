## Text description
Memora is a simulated Alexa+-style voice assistant that remembers what you tell it. You speak or type, it saves notes, recalls them with natural questions, and forgets on request. Memories and conversation persist in SQLite, so the assistant keeps context across sessions. Built with React/Vite/TypeScript, FastAPI and the browser Web Speech API. It does not integrate with real Alexa.
